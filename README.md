# avito-watch

Слежение за новыми объявлениями на Авито с уведомлениями в Telegram.

Скрипт раз в несколько минут открывает вашу поисковую выдачу в настоящем Chrome,
сравнивает с уже виденным и присылает только новые объявления: фото, название,
цену, город и ссылку.

```
🖼 [фото объявления]
🆕 Мультипекарь Redmond 7
💰 3 500 ₽
📍 Серов
https://www.avito.ru/...
```

## Возможности

- Отправка в Telegram: фото с подписью, при сбое загрузки картинки — текст.
- Дедупликация: каждое объявление приходит один раз.
- Очередь: если Telegram недоступен, объявления не теряются и досылаются позже.
- Дайджест: если новых объявлений много (например, после долгого простоя),
  приходит одно сообщение списком, а не десятки уведомлений.
- Фильтры по словам и цене.
- Автозапуск в Windows через Планировщик задач, защита от двойного запуска.

## Как это работает

Авито отдаёт обычным HTTP-запросам `HTTP 439` и проверяет TLS-отпечаток, поэтому
скрипт не «парсит» страницу библиотекой запросов, а открывает её в настоящем
Google Chrome через [Playwright](https://playwright.dev/) с постоянным профилем.

- Профиль хранится в папке `profile/` и переживает перезапуски: в нём куки Авито.
- Данные берутся из вёрстки: `[data-marker="item"]`, цена из `meta[itemprop=price]`,
  локация из `[data-marker="item-location"]`.
- Признак блокировки определяется по видимому тексту страницы, а не по HTML:
  слово «captcha» встречается в скриптах Авито и даёт ложные срабатывания.
- Состояние (какие объявления уже отправлены) лежит в `state.json`.

## Требования

- Windows 10/11.
- Python 3.11+.
- Установленный Google Chrome (не Chromium).
- Бот в Telegram и его токен.
- VPN, если провайдер блокирует Telegram (см. ниже).

## Установка

```powershell
git clone https://github.com/lre777/avito-watch.git
cd avito-watch

python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

copy config.example.json config.json
```

### Бот Telegram

1. [@BotFather](https://t.me/BotFather) → `/newbot` → придумать имя и username.
2. Скопировать токен в `config.json` → `telegram.token`.
3. Определить, куда присылать:

```powershell
.venv\Scripts\python.exe avito_watch.py --find-tg-id
```

Скрипт покажет имя бота и будет ждать сообщение 90 секунд. Напишите боту —
`chat_id` сохранится в конфиг автоматически.

### Ссылка на поиск

Соберите выдачу на avito.ru с нужными фильтрами и вставьте адрес из строки
браузера в `config.json` → `search_url`.

### Первый запуск

```powershell
.venv\Scripts\python.exe avito_watch.py --test   # показать найденное, без отправки
.venv\Scripts\python.exe avito_watch.py --once   # одна проверка с отправкой
.venv\Scripts\python.exe avito_watch.py          # работать постоянно
```

При первом запуске текущие объявления запоминаются — дальше приходят только новые.

## Ограничения Авито и что с ними делать

Это самый частый источник проблем. Авито активно защищается от автоматизации,
и скрипт регулярно упирается в одно из трёх:

| Ответ | Что значит | Что делать |
|---|---|---|
| `439` | Проверка безопасности: Авито не уверен, что запросы от человека | Открыть `avito_login.py`, пройти проверку вручную один раз. Дальше сессия живёт в профиле |
| `403` «Доступ ограничен: проблема с IP» | IP в чёрном списке (VPN, прокси, серверные адреса) | Ходить на Авито с домашнего IP, подождать 15–60 минут |
| `429` | Слишком много запросов | Увеличить `interval_seconds`, подождать |

Скрипт сам делает паузу после неудачных проверок: интервал удваивается
(10 → 20 → 40 минут, но не больше 30) и возвращается к обычному после первой
успешной проверки. Предупреждение «Авито не отдал объявления» приходит не чаще
раза в час, чтобы блокировка не превращалась в поток сообщений.

### Практические правила

1. **Интервал не меньше 5–10 минут.** При частых `429` поставьте 600 секунд.
   Чаще — почти гарантированная блокировка.
2. **Один экземпляр.** Скрипт занимает локальный порт и не даст запустить второй.
   Не запускайте тесты, пока работает основное слежение: они используют один профиль.
3. **Не удаляйте профиль без нужды.** Чистый профиль проходит проверку заново.
4. **Проверку проходит человек.** `avito_login.py` открывает видимое окно Chrome:
   вы один раз проходите проверку, скрипт сохраняет сессию. Автоматического решения
   капчи здесь нет и не будет.
5. **Не собирайте персональные данные.** Скрипт берёт только название, цену, город
   и ссылку. Телефоны и имена продавцов не сохраняются.

### Если Авито заблокировал профиль

```powershell
.venv\Scripts\python.exe avito_login.py
```

Откроется Chrome. Пройдите проверку, дождитесь появления объявлений — сессия
обновится. Старую папку `profile/` можно предварительно переименовать в
`profile_old/`, чтобы начать с чистого профиля.

## Как обойти ограничения Авито

У Авито не одна защита, а стопка:

| Слой | Что это | Как выглядит |
|---|---|---|
| Сетевой | Бан IP и rate limiting | `403` «Доступ ограничен: проблема с IP», `429` |
| Транспортный | TLS-fingerprint (почерк SSL-библиотеки) | обрыв до получения ответа |
| Прикладной | JavaScript-рендеринг, PoW-защита `firewallPow`, QRATOR, GeeTest | `439`, пустая страница, капча |
| Поведенческий | анализ мыши, скролла, частоты запросов | капча «из ниоткуда» |

Отсюда главное правило: **маскировка не снимает бан IP, а новый IP не отменяет
маскировку**. Работают оба слоя сразу.

### Слой 1. Бесплатно — сменить адрес и сбавить темп

- `403` на странице Авито прямо просит: отключить VPN, включить/выключить «авиарежим»,
  подключиться к другой сети, перезагрузить роутер. Это не опечатка — смена адреса
  реально снимает бан.
  - Перезагрузка роутера — самый быстрый бесплатный способ (если у провайдера динамический IP).
  - Точка доступа с телефона — адрес гарантированно другой, и Telegram обычно доступен напрямую.
  - Проверить свой адрес: [yandex.ru/internet](https://yandex.ru/internet).
- Интервал 10 минут, а не 5. Именно частый опрос даёт `429`, а `429` перерастает в `403`.
- Одна проверка — один запрос страницы. Не листать десятки страниц ради «свежести».

### Слой 2. Маскировка (уже встроена в скрипт)

| Что сделано | Зачем |
|---|---|
| Настоящий Chrome (`channel="chrome"`), а не Chromium | Поведение и TLS-почерк как у живого браузера |
| Постоянный профиль `profile/` | Сессия с cookie выглядит как возвращение того же человека |
| Свой `User-Agent` без слова `Headless` | В headless-режиме Playwright по умолчанию шлёт `HeadlessChrome` — это видно сразу |
| `navigator.webdriver` скрыт, `window.chrome.runtime` восстановлен | Стандартные маркеры автоматизации |
| `locale=ru-RU`, часовой пояс `Asia/Yekaterinburg`, экран 1920×1080 | Окружение совпадает с регионом и живым человеком |
| Первый заход с главной страницы, потом поиск | Прямой прыжок в глубокую ссылку выглядит подозрительно |
| Движения мыши и прокрутка перед разбором | Имитация поведения, а не мгновенный сбор DOM |
| Пауза 10 минут + случайный разброс, рост до 30 минут при сбоях | Нет ровного «роботического» ритма |
| Предупреждение о блокировке не чаще раза в час | Иначе сам скрипт заваливает чат сообщениями |

Проверить, что маскировка работает:

```powershell
.venv\Scripts\python.exe -c "import avito_watch as a; print(a.chrome_ua())"
```

### Слой 3. Прокси — единственный способ смотреть 24/7 без банов

Домашний IP Авито банит надолго, и VPN-адреса тоже в чёрных списках. Работают
**резидентные** (IP реальных домашних пользователей) и **мобильные** (IP операторов
сотовой связи) прокси. Дата-центровые Авито режет за минуты.

В конфиге:

```json
"proxy": "http://user:pass@host:port"
```

Поддерживаются `http://` и `socks5://`. Менять прокси можно прямо в конфиге —
скрипт перечитает его при перезапуске.

### Слой 4. Чего лучше не делать

- **Внутренние API Авито** (`/web/1/js/items`, `m.avito.ru/api/...`) отдают выдачу
  в JSON в разы быстрее, но эти пути прямо запрещены в `robots.txt` Авито
  (`Disallow: /api/`, `Disallow: /web/`), параметры меняются без предупреждения,
  а ответ приходит с PoW-защитой. Экономия не окупает риски.
- **Автоматическое решение капч** через 2Captcha и подобные: дёшево, но это прямое
  обход защиты, и такие аккаунты банят вместе с IP.
- **Массовый сбор персональных данных** (телефоны, имена). Это отдельная история
  по 152-ФЗ; скрипт их не собирает.
- **Сбор в обход согласия пользователей** прямо нарушает п. 2.4 соглашения Авито.
  Законно смотреть объявления самому, а не собирать чужие контакты в базу.

### Готовые решения, если не хочется писать своё

- [Duff89/parser_avito](https://github.com/Duff89/parser_avito) — бесплатный парсер
  с уведомлениями в Telegram/VK, ротацией прокси и обновлением cookies при бане.
- [xailiry/avito-parser-sdk](https://github.com/xailiry/avito-parser-sdk) — асинхронный
  SDK на Playwright.
- [mickberrad659-sketch/Avito-Parser](https://github.com/mickberrad659-sketch/Avito-Parser) —
  реализация цепочки `firewallPow`/QRATOR/GeeTest, полезно как справочник.

## Telegram и блокировки

В России провайдеры режут соединения к `api.telegram.org` по имени в TLS-рукопожатии:
TCP проходит, а handshake обрывается. В коде есть обход через IP Telegram с
нейтральным SNI, но он нестабилен: провайдер блокирует адреса выборочно.

Два надёжных варианта:

1. **VPN + раздельное туннелирование.** `chrome.exe` — напрямую (Авито видит
   домашний IP), `python.exe`/`pythonw.exe` — через VPN (Telegram доступен).
   В AmneziaVPN это «Раздельное туннелирование» → по приложениям.
2. **Релей на Cloudflare Workers.** Файл `relay_worker.js` — готовый воркер,
   который ходит в Telegram из сети Cloudflare. В конфиге:

```json
"telegram": {
  "api_base": "https://имя.аккаунт.workers.dev",
  "relay_secret": "ваш-секрет"
}
```

Инструкция по развёртыванию — в комментарии в начале `relay_worker.js`.

## Настройки

| Параметр | Описание |
|---|---|
| `search_url` | Ссылка на поисковую выдачу Авито |
| `interval_seconds` | Интервал проверок, по умолчанию 300 |
| `headless` | `true` — без окна браузера |
| `max_items_per_check` | Сколько объявлений читать со страницы |
| `notify_on_start` | Присылать сообщение при старте |
| `digest_threshold` | Сколько новых объявлений отправлять списком, а не по одному |
| `send_photos` | Прикладывать фото объявления |
| `filters.keywords` | Обязательные слова (по названию и городу) |
| `filters.exclude` | Стоп-слова |
| `filters.min_price` / `max_price` | Границы цены |
| `telegram.token` | Токен бота |
| `telegram.chat_id` | Куда присылать |
| `telegram.api_base` | Адрес релея, если используется |
| `telegram.relay_secret` | Секрет релея |

`config.json` в репозиторий не попадает: в нём токен. В git лежит только
`config.example.json`.

## Автозапуск в Windows

```powershell
$py = "$PWD\.venv\Scripts\pythonw.exe"
$script = "$PWD\avito_watch.py"
$action = New-ScheduledTaskAction -Execute $py -Argument "`"$script`""
$trigger = New-ScheduledTaskTrigger -AtLogOn -User $env:USERNAME
$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -ExecutionTimeLimit ([TimeSpan]::Zero)
Register-ScheduledTask -TaskName "AvitoWatch" -Action $action -Trigger $trigger -Settings $settings -Force
```

Управление:

```powershell
Stop-ScheduledTask -TaskName "AvitoWatch"
Start-ScheduledTask -TaskName "AvitoWatch"
Unregister-ScheduledTask -TaskName "AvitoWatch"
```

Задача запускается после входа в систему и работает, пока компьютер включён.
